# 模块 03 · 结构体与文件

> 对应练习：`practice/test076.c` ~ `test100.c`（经典 100 题第 76-100 题）。结构体把相关数据打包成整体，文件操作让程序能读写磁盘，这俩是写「能用的程序」的临门一脚。

## 学习目标

学完本模块你应该能：

1. 定义结构体、创建结构体变量、访问和修改成员
2. 用 `typedef` 给类型起别名，用指针访问结构体成员
3. 理解联合体和枚举的使用场景
4. 用 `fopen/fread/fwrite` 读写文本和二进制文件

---

## 1. 结构体：把相关数据打包

一堆变量描述同一个东西（学生：学号+姓名+成绩），散着写容易乱，打包成结构体：

```c
#include <stdio.h>

struct Student {          /* 定义结构体类型 */
    int id;
    char name[20];
    double score;
};

int main(void)
{
    struct Student s1 = {1, "tom", 92.5};   /* 声明并初始化，按顺序填 */
    struct Student s2;                      /* 先声明再逐个赋值 */

    s2.id = 2;
    strcpy(s2.name, "jerry");   /* 字符串成员不能用 =，用 strcpy */
    s2.score = 88.0;

    printf("%d %s %.1f\n", s1.id, s1.name, s1.score);  /* 用 . 访问成员 */
    return 0;
}
```

- 结构体是**自定义类型**，和 `int`、`char` 一样可以声明变量、组成数组、传给函数。
- 成员访问用点：`s1.id`。结构体数组：`struct Student class[30]; class[0].id = 1;`

> 踩坑：字符串成员赋值 `s2.name = "jerry"` 是错的——数组名不能赋值。用 `strcpy`，或者声明时整体初始化 `struct Student s = {1, "tom", 92.5};` 可以。

## 2. typedef：给类型起别名

`struct Student` 写起来啰嗦，`typedef` 起个短名：

```c
typedef struct Student {
    int id;
    char name[20];
    double score;
} Student;          /* 以后 Student 就是 struct Student 的别名 */

Student s1 = {1, "tom", 92.5};   /* 不用写 struct 了 */
```

或者直接匿名：

```c
typedef struct {
    int x;
    int y;
} Point;           /* Point 就是这个结构体的名字 */

Point p = {3, 4};
printf("(%d, %d)\n", p.x, p.y);
```

> 习惯：类型名用大驼峰（`Student`、`Point`），一眼看出是自定义类型。

## 3. 结构体指针与链表

### 结构体指针

结构体也可以被指针指向，访问成员用 `->`：

```c
Student s = {1, "tom", 92.5};
Student *p = &s;

printf("%d\n", p->id);      /* p->id 等价于 (*p).id */
p->score = 95.0;            /* 通过指针改成员 */
```

### 链表：结构体指向自己

结构体里放一个指向同类型的指针，就能一个接一个串成链表：

```c
typedef struct Node {
    int data;
    struct Node *next;   /* 指向下一个节点的指针 */
} Node;

Node a = {1, NULL}, b = {2, NULL}, c = {3, NULL};
a.next = &b;     /* 串起来：a -> b -> c -> NULL */
b.next = &c;

for (Node *p = &a; p != NULL; p = p->next) {   /* 链表遍历的固定姿势 */
    printf("%d ", p->data);    /* 1 2 3 */
}
```

- 链表 vs 数组：数组随机访问快但插入删除要搬元素；链表插入删除快（改指针就行）但不能按下标直接访问。
- 动态链表就是把这个玩法配上 `malloc/free`，边跑边加节点（`test0xx.c` 的约瑟夫环、报数游戏都靠它）。

> 踩坑：链表尾节点的 `next` 必须是 `NULL`，遍历时靠 `p != NULL` 停——忘了置 `NULL`，遍历就跑到内存外去了。

## 4. 联合体与枚举

### 联合体 union：同一块内存，多种解释

```c
union Data {
    int i;
    double d;
    char c;
};                    /* 三个成员共用同一块内存，大小 = 最大成员 */

union Data u;
u.i = 100;
printf("%d\n", u.i);   /* 100 */
u.d = 3.14;            /* 再写 d，i 的值就被覆盖了 */
printf("%f\n", u.d);   /* 3.14 */
```

- 同一时刻只有一个成员有效。省内存是它的意义（比如一个字段要么存 int 要么存 double）。
- 经典用途：`union { int i; unsigned char b[4]; }` 拆解整数的每个字节。

### 枚举 enum：给整数起有意义的名字

```c
enum Color { RED, GREEN, BLUE };   /* 默认 RED=0, GREEN=1, BLUE=2 */
enum Color c = GREEN;
if (c == GREEN) { ... }
```

比裸用 0/1/2 可读性强。也可以指定值：`enum Level { LOW = 1, MID = 5, HIGH = 9 };`

## 5. 文件操作

程序数据存在内存，一关程序就没了；写文件才能持久化。套路：**打开 → 读写 → 关闭**。

### 写文本文件

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("output.txt", "w");   /* w=写（覆盖），a=追加 */
    if (fp == NULL) {                      /* 打开失败必须检查 */
        printf("打不开文件\n");
        return 1;
    }

    fprintf(fp, "hello %d\n", 100);        /* 用法和 printf 一样，往文件里写 */
    fputs("第二行\n", fp);

    fclose(fp);                            /* 用完必须关 */
    return 0;
}
```

### 读文本文件

```c
FILE *fp = fopen("input.txt", "r");        /* r=读 */
if (fp == NULL) { ... }

char line[256];
while (fgets(line, sizeof(line), fp) != NULL) {  /* 一行一行读，读到结尾返回 NULL */
    printf("%s", line);    /* fgets 保留换行符，printf 不用再加 \n */
}
fclose(fp);
```

### 读写二进制文件

```c
int data[5] = {1, 2, 3, 4, 5};

FILE *fp = fopen("data.bin", "wb");        /* b = binary 二进制模式 */
fwrite(data, sizeof(int), 5, fp);          /* 写 5 个 int 到文件 */
fclose(fp);

int read_back[5];
fp = fopen("data.bin", "rb");
fread(read_back, sizeof(int), 5, fp);      /* 读 5 个 int 回来 */
fclose(fp);
```

`fwrite(数据地址, 每项大小, 项数, 文件)` 和 `fread` 参数对称，好记。

### 打开模式速查

| 模式 | 含义 |
|---|---|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 只写，文件存在就清空，不存在就新建 |
| `"a"` | 追加，写在文件末尾 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，清空重建 |
| 加 `b` | 二进制模式，如 `"rb"` `"wb"` |

> 踩坑：Windows 上读写二进制文件不加 `b` 会有怪问题——`\n` 被翻译成 `\r\n`、读到 `0x1A` 提前结束。二进制文件一定用 `"rb"`/`"wb"`。另外 `fclose` 忘写，数据可能还在缓冲区没落盘，文件内容是旧的。

## 6. 综合示例：学生成绩本

把结构体 + 文件 + 链表串起来的迷你项目（经典 100 题第 76-100 题的难度上限）：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int id;
    char name[20];
    double score;
} Student;

int main(void)
{
    Student s[3] = {
        {1, "tom", 92.5},
        {2, "jerry", 88.0},
        {3, "spike", 75.5}
    };

    /* 写文件 */
    FILE *fp = fopen("students.bin", "wb");
    if (fp == NULL) {
        printf("打不开文件\n");
        return 1;
    }
    fwrite(s, sizeof(Student), 3, fp);
    fclose(fp);

    /* 读文件并打印 */
    Student t[3];
    fp = fopen("students.bin", "rb");
    fread(t, sizeof(Student), 3, fp);
    fclose(fp);

    for (int i = 0; i < 3; i++) {
        printf("%d %s %.1f\n", t[i].id, t[i].name, t[i].score);
    }
    return 0;
}
```

> 提示：结构体整体 `fwrite` 很爽，但注意 `char name[20]` 这类定长成员——文件格式和自己程序绑定，跨程序交换数据时不如文本格式（JSON/CSV）通用。学 C 先掌握这里，交换格式是后话。

## 1. 指针是什么

指针 = 存地址的变量。每个变量都住在内存里，占一个门牌号（地址），指针就是记录门牌号的纸条。

```c
int a = 10;
int *p = &a;      /* &a 取 a 的地址，p 存这个地址，p 是指针 */

printf("a=%d, *p=%d\n", a, *p);   /* *p 通过地址找到 a 本身，叫解引用 */
printf("a 的地址是 %p\n", p);      /* %p 打印地址 */

*p = 20;          /* 通过指针改 a */
printf("a=%d\n", a);   /* a 变成 20，*p 就是 a 的另一个名字 */
```

三个符号别搞混：

| 符号 | 名字 | 含义 |
|---|---|---|
| `&a` | 取地址 | 拿到 a 的门牌号 |
| `int *p` | 声明指针 | p 是「指向 int 的指针」 |
| `*p` | 解引用 | 去 p 记的地址上，取出那里住着的值 |

> 踩坑：`int *p;` 只是声明了纸条，**纸条上什么都没写**。没初始化就 `*p = 1` 是往随机地址写数据，程序当场崩或留下定时炸弹。指针声明后立刻初始化，要么指向变量（`int *p = &a;`），要么指向空（`int *p = NULL;`）。

## 2. 指针的两个用途

### 用途一：函数里改外面的变量

C 的函数参数是值传递，传指针才能改原变量：

```c
#include <stdio.h>

/* 交换两个数，必须传指针，传值交换的只是副本 */
void swap(int *x, int *y)
{
    int tmp = *x;
    *x = *y;
    *y = tmp;
}

int main(void)
{
    int a = 3, b = 5;
    swap(&a, &b);           /* 传地址 */
    printf("a=%d, b=%d\n", a, b);   /* a=5, b=3，真的换了 */
    return 0;
}
```

经典练习题（`test051.c` 前后）都靠这个套路：统计函数要带回多个结果、排序函数要改数组，统统传指针。

### 用途二：让函数操作数组

数组名本身就是「首元素的地址」，把数组传给函数，传的其实是地址：

```c
int sum(int arr[], int n)   /* arr[] 等价于 int *arr，n 是长度 */
{
    int s = 0;
    for (int i = 0; i < n; i++) {
        s += arr[i];
    }
    return s;
}
/* 调用：sum(a, 5)，a 是 int 数组 */
```

> 踩坑：数组传进函数后**长度信息丢了**（只剩一个地址），所以必须额外传一个长度参数。函数里用 `sizeof(arr)` 算长度算的是指针大小（8 字节），不是数组长度。

## 3. 指针运算

指针加减 n 不是加减 n 个字节，而是**跳过 n 个元素**：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;            /* 等价于 &a[0] */

printf("%d\n", *p);      /* 10 */
p++;                     /* 指针前移一个 int（4 字节） */
printf("%d\n", *p);      /* 20 */

for (p = a; p < a + 5; p++) {   /* 指针遍历数组的经典写法 */
    printf("%d ", *p);
}
```

- `*(p + i)` 和 `p[i]` 完全等价，和 `a[i]` 也等价——**数组下标运算底层就是指针运算**。
- 两个指针相减得到元素个数：`p2 - p1`（同一数组内才有意义）。

## 4. 指针与字符串

C 没有专门的字符串类型，字符串就是**以 `'\0'` 结尾的字符数组**，用 `char *` 指向它。

```c
char s[] = "hello";       /* 数组版：6 字节，内容可以改 */
char *p = "hello";        /* 指针版：指向字符串常量，内容不可改 */

printf("%c\n", s[1]);     /* e */
printf("%s\n", p);        /* hello，%s 从地址开始一直打印到 '\0' */
```

字符串常用操作（`test0xx.c` 大量用到）：

```c
#include <string.h>

strlen(s);              /* 长度（不含 '\0'） */
strcpy(dest, src);      /* 拷贝 */
strcmp(a, b);           /* 比较：相等返回 0 */
strcat(dest, src);      /* 拼接，dest 空间必须够大 */
strchr(s, 'l');         /* 找字符，返回位置指针 */
```

- 指针数组：`char *names[] = {"tom", "jerry", "spike"};` 存多个字符串，`names[1]` 就是 `"jerry"`。
- `argv` 就是指针数组：`int main(int argc, char *argv[])`，`argc` 是参数个数，`argv[i]` 是第 i 个参数字符串。

> 踩坑：`char *p = "hello"; p[0] = 'H';` 直接崩——字符串常量存在只读区。想改的字符串必须用数组：`char s[] = "hello"; s[0] = 'H';` 合法。另一个坑：`strcmp(a, b) == 0` 才是相等，写成 `if (a == b)` 比的是两个地址，永远不相等。

## 5. 二级指针

指针自己也有地址，存「指针的地址」的变量就是二级指针：

```c
int a = 10;
int *p = &a;      /* 一级：指向 int */
int **pp = &p;    /* 二级：指向 int* */

printf("%d\n", **pp);    /* 10，两次解引用 */
**pp = 99;
printf("%d\n", a);       /* 99 */
```

用途：函数里要修改**指针本身**（比如让外层指针指向新内存）时，必须传二级指针。

## 6. 动态内存：malloc 与 free

数组长度写死太死板，`malloc` 在**运行时**按需要内存：

```c
#include <stdlib.h>

int n = 10;
int *p = (int *)malloc(n * sizeof(int));   /* 申请 n 个 int 的空间 */
if (p == NULL) {                           /* 申请失败返回 NULL，必须检查 */
    printf("内存不足\n");
    return 1;
}

for (int i = 0; i < n; i++) {
    p[i] = i * 2;                          /* 用法和数组一样 */
}

free(p);        /* 用完必须释放！不释放就是内存泄漏 */
p = NULL;       /* 释放后置空，防止误用野指针 */
```

三件套：

- `malloc(字节数)`：申请，不初始化（垃圾值）
- `calloc(个数, 每项字节)`：申请并清零
- `realloc(指针, 新字节数)`：调整大小
- `free(指针)`：释放。**有 malloc 必有 free**，一次 malloc 对应一次 free

> 踩坑三连：
> 1. **忘了 free**：程序反复申请不释放，内存越吃越多（内存泄漏）。小程序没事，常驻程序是事故。
> 2. **释放后继续用**（悬垂指针）：`free(p); printf("%d", p[0]);` 未定义行为。
> 3. **重复 free**：`free(p); free(p);` 直接崩。养成习惯：`free(p); p = NULL;`。

## 7. 函数指针

函数也有地址，函数指针让「把函数当参数传」成为可能（回调）：

```c
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

/* 第三个参数是函数指针：指向「int f(int, int)」这种函数 */
int calc(int (*op)(int, int), int x, int y)
{
    return op(x, y);
}

calc(add, 3, 4);   /* 7 */
calc(sub, 3, 4);   /* -1 */
```

`qsort` 是标准库里的经典例子，排序规则就靠传函数指针定制。

## 8. 指针自测

试着答出下面每行结果，答不出来回头看对应小节：

```c
int a[3] = {5, 6, 7};
int *p = a;
printf("%d\n", *p + 1);     /* ? */
printf("%d\n", *(p + 1));   /* ? */
printf("%d\n", p[2]);       /* ? */
printf("%d\n", *a);         /* ? */
printf("%d\n", a[1]);       /* ? */
```

答案：6、6、7、5、6。全对说明指针入门了；错一个就重看第 1、3 节。

# 模块 04 · 标准库与字符串

> 配套全部 100 题练习。C 语言本体很小，绝大多数能力在标准库里：`stdio.h`、`string.h`、`stdlib.h`、`math.h`、`ctype.h`、`time.h`。这一篇是标准库速查手册。

## 学习目标

学完本模块你应该能：

1. 熟练使用 `string.h` 的字符串函数，知道每个函数的坑
2. 会用 `stdlib.h` 的随机数、转换、排序、退出函数
3. 会用 `math.h` 和 `ctype.h` 做数学计算和字符判断
4. 会用 `time.h` 计时和生成随机种子

## 1. string.h：字符串操作

字符串 = 以 `'\0'` 结尾的字符数组。所有 `string.h` 函数都靠 `'\0'` 判断字符串在哪结束。

### 长度：strlen

```c
#include <string.h>
#include <stdio.h>

char s[] = "hello";
printf("%d\n", (int)strlen(s));    /* 5，不含结尾的 '\0' */
/* sizeof(s) 是 6（多一个 '\0'），和 strlen 差 1 */
```

### 拷贝：strcpy / strncpy

```c
char src[] = "hello";
char dst[20];

strcpy(dst, src);        /* 把 src 拷到 dst，包括结尾的 '\0' */
strncpy(dst, src, 3);    /* 最多拷 3 个字符，不会自动补 '\0'，小心！ */
```

> 踩坑：`strcpy` 不检查目标空间大小——`dst` 比 `src` 小就**溢出**，覆盖旁边内存。安全写法用 `strncpy`，但它不满 n 个字符时**不会自动补 `'\0'`**，用完手动补：`dst[n] = '\0';`。

### 比较：strcmp / strncmp

```c
char *a = "abc", *b = "abd";

if (strcmp(a, b) == 0) { ... }     /* 相等 */
strcmp(a, b) < 0                   /* a 排在 b 前面（字典序） */
strncmp(a, b, 2)                   /* 只比前 2 个字符 */
```

返回值规则：相等 0，a<b 负数，a>b 正数。**别用 `==` 直接比字符串**，那是比地址。

### 拼接：strcat / strncat

```c
char dst[50] = "hello";
strcat(dst, " world");    /* dst 变成 "hello world"，dst 空间必须够大 */
strncat(dst, "!!!", 2);   /* 最多追加 2 个字符 */
```

### 查找：strchr / strstr

```c
char s[] = "hello world";

char *p = strchr(s, 'o');       /* 找字符，返回第一次出现的位置（指针） */
printf("%d\n", (int)(p - s));   /* 4，下标 = 指针相减 */

char *q = strstr(s, "world");   /* 找子串 */
printf("%s\n", q);              /* world */
```

### 其他常用

```c
strlwr(s);      /* 转小写（Windows 有，非标准） */
strupr(s);      /* 转大写 */
memset(arr, 0, sizeof(arr));   /* 内存填充，清零数组最常用 */
memcpy(dst, src, n);           /* 内存拷贝，拷 n 字节，不认 '\0' */
```

> 踩坑：`strchr` 找不到返回 `NULL`，直接 `*p` 解引用就崩。用完先判空：`if (p != NULL)`。

## 2. stdlib.h：随机数、转换、排序

### 随机数 rand / srand

```c
#include <stdlib.h>
#include <time.h>

srand((unsigned)time(NULL));   /* 用当前时间做种子，不然每次结果都一样 */
int n = rand() % 100;          /* 0~99 的随机数 */
int m = rand() % 101 + 50;     /* 50~150 */

/* 生成 a~b 之间的随机数（含 a 和 b）： */
int r = rand() % (b - a + 1) + a;
```

> 踩坑：忘写 `srand`，程序每次运行 `rand()` 结果完全相同——随机数实际是伪随机序列，种子一样序列就一样。种子只需要设置一次，放 `main` 开头。

### 类型转换：atoi / atof

```c
int n = atoi("123");          /* 字符串转整数 */
double d = atof("3.14");      /* 字符串转浮点 */
long l = atol("123456");      /* 字符串转长整型 */

/* 更严格、带错误检测的版本： */
char *end;
long v = strtol("123abc", &end, 10);   /* 转换成功部分，end 指向剩余 */
```

### 排序：qsort

```c
#include <stdlib.h>

int cmp(const void *a, const void *b)   /* 比较函数，返回负数/0/正数 */
{
    return *(int *)a - *(int *)b;       /* 升序；降序反过来 b - a */
}

int arr[] = {5, 2, 8, 1, 9};
qsort(arr, 5, sizeof(int), cmp);   /* 数组、元素个数、元素大小、比较函数 */
```

> 踩坑：比较函数里 `*(int *)a` 的强转不能省——`void *` 指针不能直接解引用。返回 `*(int*)a - *(int*)b` 在数值极大时可能溢出，严谨写法是比较大小返回 ±1。

### 其他

```c
exit(0);              /* 立刻结束程序，0 正常 1 异常 */
system("cls");        /* 清屏（Windows）*/
abs(-5);              /* 整数绝对值 */
```

## 3. math.h：数学计算

```c
#include <math.h>

sqrt(16);         /* 4.0    开平方 */
pow(2, 10);       /* 1024.0 幂 */
fabs(-3.5);       /* 3.5    浮点绝对值 */
floor(3.7);       /* 3.0    向下取整 */
ceil(3.2);        /* 4.0    向上取整 */
round(3.5);       /* 4.0    四舍五入 */
fmod(10, 3);      /* 1.0    浮点取模 */
```

> 踩坑：MinGW/GCC 下链接数学函数要加 `-lm`（`gcc test.c -lm`），否则报 `undefined reference to 'sqrt'`。Windows 的 MinGW 一般默认带，Linux 必须手动加。

## 4. ctype.h：字符判断

```c
#include <ctype.h>

isalpha(c)     /* 是不是字母 */
isdigit(c)     /* 是不是数字 */
isalnum(c)     /* 字母或数字 */
isspace(c)     /* 空白（空格、换行、制表） */
islower(c)     /* 小写字母 */
isupper(c)     /* 大写字母 */
tolower(c)     /* 转小写，返回转换后的字符 */
toupper(c)     /* 转大写 */
```

统计字符串里字母数字个数（经典 100 题第 17 题）的标准写法：

```c
char s[] = "abc123 !!";
int letters = 0, digits = 0;
for (int i = 0; s[i] != '\0'; i++) {
    if (isalpha(s[i])) letters++;
    if (isdigit(s[i])) digits++;
}
```

> 踩坑：`isdigit` 等的参数是 `unsigned char` 范围内的值，中文等多字节字符逐字节判断会得到未定义结果。判断 ASCII 文本没问题，处理中文先转成宽字符（`wctype.h`，进阶话题）。

## 5. time.h：时间与计时

```c
#include <time.h>
#include <stdio.h>

time_t now = time(NULL);              /* 当前时间的秒数（时间戳） */
printf("%ld\n", (long)now);

/* 计时：程序跑了多少秒 */
clock_t start = clock();
/* ... 要测的代码 ... */
clock_t end = clock();
printf("耗时 %.3f 秒\n", (double)(end - start) / CLOCKS_PER_SEC);
```

## 6. stdio.h 补充：输入输出细节

### printf 占位符大全

| 占位符 | 类型 | 示例 |
|---|---|---|
| `%d` | int | `printf("%d", 42)` |
| `%ld` | long | `%lld` 是 long long |
| `%u` | 无符号 int | `%lu` 无符号 long |
| `%f` | float/double | `%.2f` 保留两位小数 |
| `%e` | 科学计数 | `1.2e+03` |
| `%c` | 字符 | |
| `%s` | 字符串 | |
| `%p` | 地址（指针） | |
| `%x` | 十六进制 | `%X` 大写字母 |
| `%o` | 八进制 | |
| `%%` | 百分号本身 | |

宽度和精度：`%5d` 右对齐占 5 格，`%-5d` 左对齐，`%05d` 补零，`%8.2f` 总宽 8 小数 2 位。

### scanf 细节

```c
int n;
double d;
char c;
char s[50];

scanf("%d", &n);        /* 整数，必须 & */
scanf("%lf", &d);       /* 浮点：double 用 %lf，float 用 %f */
scanf(" %c", &c);       /* 字符：%c 前加空格，跳过上次遗留的换行 */
scanf("%s", s);         /* 字符串：不加 &，遇空格就停 */
```

> 踩坑：连续用 `scanf`，上一次输入留在缓冲区的 `\n` 会被下一次 `%c` 读走，导致「字符读不进去」。两种解法：`scanf(" %c", &c)` 前加空格，或者读完用 `fflush(stdin)`（非标准，GCC 下用 `while (getchar() != '\n');` 清空）。

## 7. 标准库学习心法

1. **先查后写**：`man 函数名`（Linux）或搜索引擎，看参数、返回值、示例，别凭印象猜。
2. **返回值就是合同**：`fopen` 返回 NULL、`strchr` 返回 NULL、`scanf` 返回成功读取的个数——C 的函数用返回值报告成败，检查返回值是好习惯。
3. **踩坑都写在手册里**：`strncpy` 不补 `'\0'`、`rand` 要种子、`fgets` 保留换行——这些「已知问题」构成了 C 的学习成本，也是面试最爱。

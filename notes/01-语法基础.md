## 1. 环境与第一个程序

- 检查编译器：`gcc --version`。Windows 上装 MinGW-W64 后把 `bin` 目录加入 PATH。
- C 是编译型语言：源码 `.c` 经过编译、链接变成 `.exe`（Windows）/ 无扩展名可执行文件（Linux），程序才能跑。
- 一个源文件 = 一个程序的最小单位。多文件项目用 Makefile 管理（见模块 05）。

```c
#include <stdio.h>   /* 引入标准输入输出库，printf/scanf 都在里面 */

int main(void)       /* 程序入口，有且只有一个 main 函数 */
{
    printf("hello, world\n");  /* \n 是换行，没有它输出会挤在一行 */
    return 0;        /* 返回 0 表示正常结束，操作系统会读这个值 */
}
```

编译运行：

```bash
gcc -Wall -o hello hello.c   # -Wall 显示所有警告，-o 指定输出文件名
./hello                      # Windows 上编译出 hello.exe，直接敲 hello
```

> 踩坑：`printf` 里中文乱码？Windows 控制台编码问题，程序开头加 `system("chcp 65001")` 或直接用英文输出。另外 MinGW 编译出的 exe 双击会闪退，因为程序跑完窗口就关了，要在 cmd 里运行或结尾加 `system("pause")`。

## 2. 变量与数据类型

C 的变量**必须先声明后使用**，声明时要指定类型，类型决定占用内存大小和能存的值。

| 类型 | 关键字 | 字节 | 范围 |
|---|---|---|---|
| 字符 | `char` | 1 | -128~127（存 ASCII 字符，如 `'A'` 是 65） |
| 短整型 | `short` | 2 | -32768~32767 |
| 整型 | `int` | 4 | -21亿~21亿 |
| 长整型 | `long` | 4/8 | 平台相关（Windows 上是 4 字节） |
| 单精度浮点 | `float` | 4 | 6-7 位有效数字 |
| 双精度浮点 | `double` | 8 | 15-16 位有效数字 |

```c
#include <stdio.h>

int main(void)
{
    int age = 30;            /* 整型 */
    double salary = 3.14;    /* 浮点默认 double，float 要写 3.14f */
    char grade = 'A';        /* 字符用单引号 */

    printf("age=%d, salary=%.2f, grade=%c\n", age, salary, grade);
    /* %d 整型  %f 浮点(%.2f保留两位)  %c 字符  %s 字符串 */
    printf("sizeof(int)=%d\n", (int)sizeof(int));  /* sizeof 求字节数 */
    return 0;
}
```

- `printf` 的占位符和变量要**一一对应**：类型对不上（比如 `%d` 配了 `double`）输出就是乱的，编译器会给警告。
- 常量用 `const` 修饰（`const int MAX = 100;`）或 `#define` 宏（`#define MAX 100`）。常量定义放文件顶部。

> 踩坑：整数除整数得整数，`5 / 2` 结果是 `2` 不是 `2.5`。想要小数，至少一个操作数写成浮点：`5.0 / 2` 或 `5 / 2.0`。

## 3. 运算符

优先级从高到低（简化记忆）：`!` → 算术（`* / %` → `+ -`）→ 关系（`< <= > >=`）→ 相等（`== !=`）→ `&&` → `||` → 赋值。搞不清就加括号。

```c
int a = 10, b = 3;
a / b      /* 3   整除 */
a % b      /* 1   取模（余数） */
a++        /* 先用后加：表达式值是 10，之后 a 变成 11 */
++a        /* 先加后用：表达式值是 12（假设 a=11） */
a > 5 && b < 5   /* 1  逻辑与，C 里真=1 假=0，非0都是真 */
!a         /* 0  逻辑非 */
```

- 复合赋值：`a += b` 即 `a = a + b`，还有 `-=` `*=` `/=` `%=`。
- 相等是 `==`（两个等号），赋值是 `=`（一个等号）。**`if (a = 1)` 永远为真**，这是 C 新手第一大坑。
- `&&` 和 `||` 有**短路**：`&&` 左边为假右边不执行，`||` 左边为真右边不执行。可以利用短路避免除零：`b != 0 && a / b > 1`。
- 三元运算符：`a > b ? a : b` 取较大值，等价于 if-else 的简写。

## 4. 分支结构

### if-else

```c
#include <stdio.h>

int main(void)
{
    int score = 85;
    if (score >= 90) {
        printf("A\n");
    } else if (score >= 60) {
        printf("B\n");
    } else {
        printf("C\n");
    }
    return 0;
}
```

- 代码块用花括号 `{ }` 包住，**即使只有一行也建议写花括号**，防止以后加语句时掉进坑里。
- 嵌套 if 能拍平就拍平，可读性优先。

### switch

```c
switch (grade) {
    case 'A':
        printf("优秀\n");
        break;          /* 没有 break 会继续往下穿透执行 */
    case 'B':
        printf("良好\n");
        break;
    default:
        printf("其他\n");   /* 都不匹配走 default */
}
```

- `case` 后面必须是整数常量（`char` 也算整数），**不能是浮点或字符串**。
- 忘写 `break` 导致「穿透」是第二大坑：两个 case 的代码会连续执行。

## 5. 循环结构

### for 循环

```c
for (int i = 1; i <= 9; i++) {      /* 初始化; 条件; 步进 */
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%d\t", j, i, i * j);   /* \t 是制表符，对齐用 */
    }
    printf("\n");
}
```

### while 循环

```c
int n = 1, sum = 0;
while (n <= 100) {       /* 先判断再执行，可能一次都不执行 */
    sum += n;
    n++;
}
```

### do-while 循环

```c
int n = 1;
do {
    printf("n=%d\n", n);
    n++;
} while (n <= 3);        /* 先执行再判断，至少执行一次 */
```

### 循环控制

- `break`：跳出**整个**循环；`continue`：跳过本次，进入下一次。
- `for(;;)` 是死循环写法，跳出靠循环体内的 `break`。
- 经典套路：**flag 标记法**——素数判断、寻找目标值都靠一个标志变量：

```c
/* 判断 n 是不是素数 */
int is_prime = 1;                      /* 先假设是素数 */
for (int i = 2; i * i <= n; i++) {     /* 只试到 sqrt(n) 就够了 */
    if (n % i == 0) {
        is_prime = 0;                  /* 被整除，推翻假设 */
        break;
    }
}
```

> 踩坑：循环变量在 `for` 里声明（C99 标准支持），循环外就不能再用了。老编译器（或开了老标准）会报错，把变量提到循环外声明最保险。

## 6. 数组

数组是一段**连续内存**，存同一类型的一组数据，下标从 0 开始。

```c
int scores[5] = {90, 85, 77, 92, 68};   /* 声明并初始化 */
int a[5] = {0};                         /* 全部初始化为 0，简写 */
int b[] = {1, 2, 3};                    /* 长度自动算，= 3 */

scores[0] = 100;        /* 第一个元素 */
printf("%d\n", scores[4]);  /* 最后一个元素，下标是 长度-1 */

int len = sizeof(scores) / sizeof(scores[0]);  /* 算数组长度的惯用法 */

for (int i = 0; i < len; i++) {         /* 遍历数组的固定姿势 */
    printf("%d ", scores[i]);
}
```

- 二维数组：`int m[3][4]` 是 3 行 4 列，`m[i][j]` 访问第 i 行第 j 列。
- 字符数组存字符串：`char s[] = "hello";`（末尾自动加 `'\0'` 结束符）。

> 踩坑：C 的数组**不检查越界**！`int a[5]; a[10] = 1;` 编译通过，运行结果是未定义的——可能覆盖别的变量、可能崩溃，而且 bug 出现的位置往往离越界点很远。这是 C 最臭名昭著的问题，数组下标永远自己盯着。

## 7. 函数

函数 = 一段有名字的代码块，可以被反复调用。用函数把大问题拆成小问题。

```c
#include <stdio.h>

int max(int x, int y)     /* 返回类型 函数名(参数列表) */
{
    return x > y ? x : y;
}

void print_line(int n)    /* void 表示不返回值 */
{
    for (int i = 0; i < n; i++) {
        printf("-");
    }
    printf("\n");
}

int main(void)
{
    printf("%d\n", max(3, 5));
    print_line(10);
    return 0;
}
```

要点：

- **函数要先声明后使用**：函数定义放 `main` 前面，或先在文件顶部写声明（函数原型）：`int max(int x, int y);`。
- 参数是**值传递**：函数里改参数不影响调用处的变量。想改外面的值，必须传指针（模块 02 讲）。
- 递归 = 函数自己调用自己。写递归抓三件事：**结束条件、递推公式、问题变小**：

```c
/* 求 n 的阶乘：n! = n * (n-1)!，0! = 1 是结束条件 */
long factorial(int n)
{
    if (n <= 1) {
        return 1;                 /* 结束条件 */
    }
    return n * factorial(n - 1);  /* 递推公式，n 每次变小 */
}
```

> 踩坑：递归没有正确的结束条件会无限调用，直到**栈溢出**崩溃（俗称爆栈）。写完先手算一层最小的情况对不对。

## 8. 输入输出与类型转换

```c
#include <stdio.h>

int main(void)
{
    int age;
    double height;

    printf("请输入年龄和身高: ");
    scanf("%d%lf", &age, &height);   /* 变量前必须加 & 取地址！ */

    printf("年龄 %d，身高 %.2f\n", age, height);
    return 0;
}
```

- `scanf` 第二坑：**变量前必须写 `&`**（取地址符），忘写程序直接崩。字符数组（字符串）例外，不用 `&`。
- 类型转换：`(int)3.99` 得到 `3`（截断，不是四舍五入）。整数转浮点自动提升；浮点转整数必须显式强转，否则编译器警告。

## 9. 常见报错速查

| 报错 | 原因 |
|---|---|
| `undefined reference to 'xxx'` | 调用了没定义/没链接的函数，函数名写错或库没链接 |
| `expected ';' before ...` | 上一句漏了分号 |
| `expected '}' before ...` | 花括号没配对 |
| `control reaches end of non-void function` | 有返回类型的函数没写 `return` |
| `warning: implicit declaration` | 函数没声明就用（缺头文件） |

> 心法：**编译错误从第一条开始改**，后面的错误往往是第一条引起的连锁反应；警告也全修，警告里常常藏着真 bug。

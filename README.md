# ctest100

C 语言学习与练习仓库。以《C语言经典 100 题》为主线，每题一练，配套模块化基础知识笔记。

## 目录结构

| 目录 | 内容 |
|---|---|
| `notes/` | 5 个模块的 C 语言基础知识笔记（要点 + 可运行代码 + 踩坑提示） |
| `practice/` | 100 题练习，`test001.c` ~ `test100.c` 每题一个文件，题目文档按 25 题一份 |
| `.gitignore` | 忽略编译产物（a.out、exe、o 等） |

## 学习路线

| 阶段 | 题目 | 内容 | 配套笔记 |
|---|---|---|---|
| 01 入门热身 | 1-25 | 排列组合、利润计算、素数、水仙花数、质因数分解、最大公约数 | 01-语法基础 |
| 02 循环与数组 | 26-50 | 阶乘、杨辉三角、报数游戏、排序、数组操作 | 01-语法基础 |
| 03 指针与字符串 | 51-75 | 字符串操作、指针数组、结构体、链表入门 | 02-指针与内存、04-标准库与字符串 |
| 04 文件与综合 | 76-100 | 文件读写、内存管理、综合应用 | 03-结构体与文件、05-编译调试工具链 |

## 学习约定

1. 每题先看题目自己写，写完再和 `testXXX.c` 对照
2. 本地编译验证：`gcc -o testXXX testXXX.c`，运行输出符合题意才算过
3. 当天学完 commit 一次，提交信息格式：`add testXXX-XXX: 题目主题`
4. 笔记只增不减，学新的不推翻旧的

## 编译与调试

gcc 编译参数、Makefile 编写、gdb 调试的详细笔记见 `notes/05-编译调试工具链.md`。

快速上手：

```bash
gcc -g -Wall -o test001 test001.c   # 编译（-g 加调试信息，-Wall 显示所有警告）
./test001                            # 运行
gdb ./test001                        # 调试
```
